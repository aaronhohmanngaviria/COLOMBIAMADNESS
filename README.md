# Runas de Cobre — Edición 32 Bits

ARPG por turnos con estética pixel-art de 32 bits, ambientado en mitos y leyendas colombianas.
Recorre **12 tierras malditas**, purga a sus guardianes y forja tu leyenda.

## 🎮 Controles

| Acción | Teclado | Táctil |
|---|---|---|
| Mover | `WASD` / Flechas / Clic | D-Pad |
| Atacar | Clic / Espacio | Botón **A** |
| Salto (2 casillas) | `Shift` + Mover | Botón **K** |
| Ficha de estadísticas | `C` | Toca la barra superior |
| Pausa / menú | `Esc` | — |

Las **casillas carmesí** indican ataques enemigos telegrafiados. Cada paso consume un turno.

## ⚔️ Estadísticas principales

- **DAÑO** — puntos por golpe
- **VIDA** — corazones (2 puntos = 1 ♥)
- **GANANCIA DE EXP** — % de experiencia obtenida
- **GANANCIA DE ORO** — % de oro obtenido
- **ARMADURA** — reduce daño y añade probabilidad de bloqueo

## 🗺️ Contenido

- **12 capas/tierras** con temática propia (Laguna de Bachué, Cascada de Bochica, El Dorado, La Patasola, El Sombrerón, La Madremonte, El Mohán, La Llorona, El Hombre Caimán, El Silbón, El Duende, La Buina).
- **Jefes únicos** con fases, invocación de esbirros y ataques telegrafiados.
- **Sistema de equipo** por ranuras: Malla, Pantalón, Arma, Escudo (Común → Raro → Épico → Legendario).
- **Mejoras rúnicas** al subir de nivel (11 tipos).
- **Tienda del Guardián** entre capas.
- **Objetos legendarios** exclusivos por jefe.
